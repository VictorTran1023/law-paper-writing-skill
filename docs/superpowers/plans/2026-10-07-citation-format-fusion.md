# 引注体例融合方案：以《法学引注手册》（第二版）为技能补入默认引注格式

> **目标**：以《法学引注手册》（第二版，北京大学出版社）为素材，把引注规范与方法提炼为 `VictorTran1023/law-paper-writing-skill`（下称 A）可用的**默认工作体例**——未指定目标期刊时，AI 输出的引注默认按手册体例书写；目标期刊正式要求仍优先。**不整本搬书**：只做"规则提炼＋短示例＋条号回查标记"。
>
> **执行位置**：本分支 `feature/citation-format-merge`（main 与并行开发分支均不受影响）。
>
> **基线与来源**：A = `main@638a721`（v1.1.0）；素材 = 手册纸质扫描件 187 页（400dpi、无文字层；双通道 OCR 后逐条核对）。
>
> **实施说明**：本文件为实施记录；完成后按"六、验收标准"与本机实测结果核对。

## 一、设计原则

1. **保持 A 的形态**：单技能、纯 Markdown、git 工作流；新增内容融入现有文件结构，不新增顶层目录。
2. **手册定位**：默认体例（未指定期刊时适用），不是"所有法学期刊的统一强制标准"；期刊正式要求优先——保持 A 既有立场不变。
3. **核对纪律**：凡进入技能的文字（示例、格式、引文），逐字对照原书页面放大核对后写入；不可靠处不写或保留标记，绝不猜测补全。
4. **不整本搬运**：手册为正式出版物，只提炼规则＋短示例＋条号（第X条）回查标记。
5. **力度照书**：保留手册的规范力度分级（应当／一般／宜／可以），不把"可以"写成"必须"。
