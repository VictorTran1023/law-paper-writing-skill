# 引注审核

- [ ] 每项来源性主张后均有对应标识
- [ ] 正文标识与脚注双向对应
- [ ] 每条脚注能追到来源编号和原始资料
- [ ] 来源登记中的完整著录、原始位置、精确定位、核验日期和允许用途完整
- [ ] 最终稿所用来源均为 `VERIFIED`，无 `PARTIAL`、`LEAD_ONLY` 或 `UNUSABLE`
- [ ] 直接引语均有精确位置
- [ ] 转述、二手转引和译文均已说明
- [ ] 法律规范版本及效力已经核验
- [ ] 案件名称、案号、法院和日期已经核验
- [ ] 数据口径、范围、时间和发布者完整
- [ ] 无孤立参考文献或脚注
- [ ] 适用的必填字段完整；不适用的条件字段明确标注 `N/A` 并说明依据；可选备注可留空
- [ ] 无虚构字段、`[待核]`、待补充或待核验等未完成占位
- [ ] 引注格式符合适用体例：未指定期刊时符合《法学引注手册》体例（页码、版次、卷期、案号、文号与外文写法等），有目标期刊正式要求的从其要求
- [ ] 再次引用按体例处理（同前注／同上注等形式；内容定稿前和投稿时，不建议使用略写形式）
- [ ] 标点与符号符合体例（并列书名号不加顿号、公文字号用六角括号、单书名号不写成尖括号等）
