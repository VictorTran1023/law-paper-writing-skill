# 合成摘要对照

以下均为人为构造的教学材料，题目、观点与结论都是虚构的，不是真实研究、学说或期刊范文。对照的规律从审读反馈中两类真实摘要的差异归纳而来，但没有采用其中任何原文。规则见 [目标期刊适配](../../references/journal-adaptation.md)“摘要与关键词”；字数、分段与不加引注等体例见 [引注格式规范](../../references/citation-format.md) 第17条。示范展示判断理由，不是可以套用的句式。

## 不合格的写法

> 行政约谈是推进治理现代化的重要抓手，也是建设法治政府的关键环节。近年来，行政约谈在实践中取得显著成效的同时，也暴露出诸多亟待解决的问题。针对已有研究的不足，本文试图从多个维度深入剖析行政约谈存在的问题及其成因，并在此基础上提出完善行政约谈制度的对策建议，以期为法治政府建设提供有益参考，具有重要的理论价值和实践意义。

| 句子 | 问题 |
|---|---|
| 第一句 | 以意义口号起笔，说的是人所共知的定位，没有进入本文的问题 |
| 第二句 | “取得成效的同时也暴露出诸多问题”是套语，读者仍不知道问题是什么 |
| 第三句 | 只说“针对已有研究的不足”，没说不足在哪里；“多个维度”“深入剖析”“对策建议”都没有内容，读不出本文的观点 |
| 末句 | “以期……提供有益参考”“具有重要的理论价值和实践意义”是自我评价 |

整段删去套语后几乎不剩信息：既没有可以反驳的判断，也看不出创新之处。

## 合格的写法

> 行政约谈以协商面目出现，却常被后续决定援引为处罚、许可或信用评价的依据，被约谈人既难以拒绝约谈，也难以对约谈内容寻求救济。既有研究多将约谈归入行政指导，侧重其柔性功能，未能解释约谈记录在后续程序中产生的约束效果。约谈的法律性质不应取决于名称，而应取决于约谈结论是否被后续决定援引：仅用于信息交流的约谈属于行政指导；结论被援引为不利决定依据的，应视为程序性行政行为，适用告知、陈述申辩与记录公开等正当程序要求。以“结论是否被援引”区分两类约谈，可以在保留协商空间的同时，为被约谈人提供救济入口。

| 句子 | 承担的要素 |
|---|---|
| 第一句 | 研究的问题及其重要性：直接写出矛盾所在和受影响的人，不铺陈背景 |
| 第二句 | 既有研究的不足：一句点明不足落在哪里，不展开研究现状 |
| 第三句 | 主要观点与创新：给出可以检验、也可以反驳的判断标准，以及按标准分类后的结论 |
| 末句 | 论证得出的效果，用陈述代替自我评价 |

全段不用第一人称；“本文”可以用，但能直接陈述观点时，不必先写“本文认为”。

## 可迁移的检查

1. 删去第一句，读者会不会损失信息？不会的，说明它只是意义铺垫。
2. “既有研究的不足”是否写明了不足落在哪里？
3. 主要观点是否是一个可以被反驳的具体判断，而不是“提出对策建议”“构建制度体系”？
4. 末句是在陈述论证结果，还是在评价本文的价值？
5. 把“取得成效的同时”“多维度”“深入剖析”“以期”“具有重要意义”一类词删掉后，句子是否仍有内容？
