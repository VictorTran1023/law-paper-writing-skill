# chinese-law-paper-writing

> 指导中国大陆法学类CSSCI期刊论文写作的方法论Skill

## 概述

这个Skill提炼了一份关于法学CSSCI期刊论文写作的系统方法论，覆盖从选题到投稿的完整流程。

## 适用对象

- 法学专业硕士/博士研究生，正在撰写或计划撰写CSSCI期刊论文
- 青年法学学者，需要系统化的论文写作框架
- 任何需要了解中国法学学术写作规范的研究者

## Skill 涵盖内容

| 阶段 | 内容 |
|---|---|
| **第一步** | 确立问题意识：法学问题的判别标准（"规范性"）、来源路径、循环往复的迭代方法论、**选题自检清单（7项）** |
| **第二步** | 参考文献搜集与分类：七大分类体系（学术著作、学术论文、法律规范、党内法规/讲话、政策文件、案例、新闻报道） |
| **第三步** | 论文结构写作：问题的提出（500–1200字）、正文（3–4节，并联/串联逻辑）、结语（500–1000字）、题目（灵魂结晶） |
| **第四步** | 摘要与关键词：中文摘要四要素、英文摘要注意事项、关键词选取策略 |
| **常见写作陷阱** | 8大高频退稿原因自查表（含典型表现与修复方向） |
| **引注规范** | 《法学引注手册》核心要点速查 |
| **投稿与时间管理** | 四阶段时间线（选题→初稿→修改→投稿）、期刊分类选择参考 |

## 使用方法

在Hermes对话中提及法学论文写作相关任务时，Skill会自动加载。你也可以手动触发：

```
请按照 chinese-law-paper-writing skill 的方法，帮我分析"行政公益诉讼中检察机关调查核实权的边界"这个问题意识是否适合作为一篇CSSCI论文的选题。
```

典型使用场景：

- 选题评估与问题意识打磨（配合选题自检清单）
- 论文大纲搭建
- 参考文献范围规划
- 正文逻辑结构审查
- 常见写作陷阱自查
- 摘要与结语质量检查
- 投稿策略选择

## 来源

方法论源于一份题为《关于中国法学类CSSCI期刊发表论文的写作过程与方法》的文档，经提炼与结构化后形成本Skill。后续补充了选题自检清单、摘要与关键词写法、常见写作陷阱、引注规范、投稿与时间管理等内容。
